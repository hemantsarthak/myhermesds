# Pincode India — pincode.tekify.xyz

A searchable index of Indian postal codes: 38,936 post offices across 23,913 pincodes,
585 districts and 35 states, built as a static site from a local dataset.

## What it is

Most address forms ask for a pincode and then discard the useful part — which post
offices sit inside it, which district, which state. This site keeps that mapping
readable and searchable. Metro pincodes are the interesting case: `400002` covers
226 individual post offices, and every form in the country flattens that to one entry.

## Stack

No framework, no bundler, no runtime dependency. Every page is one self-contained HTML
file with inline CSS, generated by a single Python script. The full dataset also ships
as JSON so search runs entirely in the browser.

| Piece | What it does |
|---|---|
| `scripts/build_site.py` | Generates `site/` from `data-source/indiapicodedata.json` |
| `scripts/verify_site.py` | Post-build gate: broken links, sitemap drift, metadata, platform limits |
| `data-source/` | Source dataset (committed — the build depends on it) |
| `site/` | Generated output (gitignored, deployed to Cloudflare Pages) |

## Build

```bash
python3 scripts/build_site.py          # 8,000 pincode pages + 585 districts + 35 states
python3 scripts/verify_site.py         # must print VERIFY: clean before deploying
```

`--pincode-limit N` controls how many pincode pages are emitted. Cloudflare Pages Free
allows 20,000 files per site, and there are 23,913 unique pincodes, so the remainder are
served through the generic `/lookup/?pincode=` route and the client-side search.

## Deploy

```bash
npx wrangler pages deploy site --project-name=pincode-india
```

## Data

Compiled from India Post post-office listings: post office name, pincode, city, district,
state. One row in the source has a 5-digit pincode and is dropped; duplicate
`(pincode, post office)` pairs are collapsed. District and state labels are canonicalised
by case-folded frequency, because the source contains the same place as both `Bishenpur`
and `BISHENPUR`, which would otherwise produce two URLs for one district.
